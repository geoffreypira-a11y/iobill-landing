IO BILL sur mobile

Votre facturation dans la poche.

IO BILL est une application web installable sur iPhone et Android depuis le navigateur, sans passer par un store. Une fois ajoutée à l'écran d'accueil, elle s'ouvre en plein écran comme une application, avec votre compte et vos données habituels.

⚡ En bref

Il n'existe pas d'application à télécharger sur l'App Store ou Google Play. IO BILL est une application web progressive (PWA) : vous l'installez depuis le navigateur de votre téléphone en quelques secondes, et elle se met à jour toute seule. C'est la même application que sur ordinateur, incluse dans votre abonnement.

1.Une application web installable, sans store

IO BILL s'appuie sur la technologie PWA (Progressive Web App) : un manifeste d'application et un service worker permettent d'installer le site app.iobill.online sur l'écran d'accueil de votre téléphone. Concrètement :

  • Icône sur l'écran d'accueil et ouverture en plein écran, sans barre d'adresse ;
  • Mises à jour automatiques : pas de version à télécharger, vous avez toujours la dernière ;
  • Mêmes données partout : ce que vous créez sur le téléphone est immédiatement visible sur l'ordinateur, et inversement ;
  • Notifications : les notifications web peuvent être activées depuis l'application (selon votre appareil et votre navigateur).

2.Installer IO BILL sur iPhone et Android

AppareilComment installer
iPhone / iPad Ouvrez app.iobill.online dans Safari, touchez le bouton Partager, puis « Sur l'écran d'accueil ».
Android Ouvrez app.iobill.online dans Chrome, ouvrez le menu ⋮, puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
Ordinateur Utilisez simplement app.iobill.online dans un navigateur récent (Chrome, Firefox, Safari, Edge).

3.Ce que vous pouvez faire depuis votre téléphone

  • Créer un devis ou une facture chez le client ou entre deux rendez-vous, avec auto-complétion des coordonnées d'entreprise via la base SIRENE ;
  • Photographier une facture fournisseur ou déposer un PDF : l'OCR crée le brouillon d'achat à valider ;
  • Suivre vos devis envoyés, acceptés par vos clients depuis leur portail, et les convertir en facture ;
  • Consulter vos factures, leurs statuts de paiement et les relances en cours ;
  • Échanger avec votre expert-comptable via la messagerie intégrée.

4.Ce qu'il faut savoir

  • Une connexion internet est nécessaire : IO BILL ne propose pas de mode hors-ligne pour créer des documents ;
  • Il n'y a pas d'application native sur l'App Store ni sur Google Play : méfiez-vous de toute application qui se présenterait comme « IO BILL » dans un store ;
  • La signature électronique eIDAS (Yousign) est en cours de développement ; aujourd'hui, vos clients acceptent un devis en ligne depuis leur portail.
